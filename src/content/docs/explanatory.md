## なにをつくったか

TypeScript ライブラリとして動作する組版エンジンを開発しました．分かりやすく換言すると，大規模言語モデル（LLM）や他のアプリケーションから美しく整形された文書を作成するために，**高品質な組版処理を通常の TypeScript プログラムと同じように呼び出せる仕組み**を作った！ということになります（図 1）．

![ヘッドレス組版エンジン minitype．アプリケーションや AI から美しい文書を生成する技術により，多様な文書生成ワークフローに高品質な組版処理を組込む．組版処理：文書や図表等の要素を適切に配置して，読みやすい文書に仕上げる処理．](/zenn-images/042c1c34f2f0-20260830.png)  
_図 1：minitype により作成可能な文書の例．_

GUI を持たず，プログラムからの操作を前提とするブラウザ（例：Playwright，Puppeteer）は[ヘッドレスブラウザ](https://ja.wikipedia.org/wiki/%E3%83%98%E3%83%83%E3%83%89%E3%83%AC%E3%82%B9%E3%83%96%E3%83%A9%E3%82%A6%E3%82%B6)と呼ばれますが，これになぞらえて minitype では，組版処理を固有の組版言語（DSL）や GUI から切り離して，汎用プログラミング言語から直接実行可能な組版エンジンを「**ヘッドレス組版エンジン**」と定義しています．

### minitype の特徴

minitype は大きく次の特徴を有します．これらの特徴により，特定のアプリケーションや専用言語の中に閉じることなく，TypeScript/JavaScript のエコシステムから高度に組版された文書を柔軟に生成できるように設計されています．

-   **npm ライブラリ**（パッケージ）として提供され，JavaScript のランタイム上に簡単にインストール可能
    -   **複数の JavaScript ランタイム**（Node.js，Bun，Web ブラウザ）で動作
-   **TypeScript オブジェクトや関数**によって文書構造やレイアウトを記述
-   ライブラリが提供する API を呼び出すことにより組版処理を実行<sup>[\[2\]](#fn-6179-2)</sup>
-   **高度な組版処理**に対応（[日本語組版処理の要件](https://www.w3.org/International/jlreq) や [Knuth–Plass Line-Breaking Algorithm](https://onlinelibrary.wiley.com/doi/abs/10.1002/spe.4380111102) をベースとする）
-   PDF 生成のみならず，組版結果のレイアウトや診断情報を取得可能

### 構成要素

minitype では，以下の 3 つの TypeScript パッケージを提供しています．

-   [**@minitype/minitype**](https://www.npmjs.com/package/@minitype/minitype)：組版処理を担当するコアエンジン
-   [**create-minitype**](https://www.npmjs.com/package/create-minitype)：CLI または API 経由で minitype を用いた文書プロジェクトを簡便にセットアップするツール
-   [**@minitype/vite-plugin**](https://www.npmjs.com/package/@minitype/vite-plugin)：文書のリアルタイムプレビューを実現する Vite プラグイン

これらのパッケージは npm 上で配布されています．minitype 本体については [PolyForm Noncommercial License 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0) としつつも，個人利用や同人利用に関しては自由に使用していただくことが可能です（商用利用についてはお問い合わせください）．また，create-minitype，vite-plugin についてはオープンソース（MIT ライセンス）で公開しています．

## 開発背景

ここで，minitype を開発した背景として，そもそも組版とは何か？という話と，変化しつつある文書生成について説明します．

### 文書生成と組版の広がり

我々は情報を残したり，その情報を共有したりするために，日々様々な**文書**を作成しています．ここでいう文書には，レポートや論文，書籍に限らず，申請書，請求書，マニュアル，スライド等，情報を一定の形式に整理した幅広い媒体が含まれます．特に，PDF を中心とした固定の文書フォーマットは，情報の保存性や可搬性，読みやすさに優れることから，Web が普及した現在でも依然として頻繁に使用されています．

ここで重要となるのが**組版**です．組版とは，情報を読みやすく整えるために，文字や図版等の要素を適切に配置する作業を指します．文書中のレイアウトやフォントは情報の理解のしやすさや信頼性に影響を与えると報告されている（[論文 1](https://www.tandfonline.com/doi/abs/10.1080/01449290410001715714)，[論文 2](https://www.sciencedirect.com/science/article/abs/pii/S0378720617308741)）ことからも，情報を正確かつ効果的に伝える上で，適切な組版は欠かせない要素です．

また現在では，こうした文書の作られ方も変化しつつあります．これまでのように，人が文章を書き，見た目を整えて文書を作るだけでなく，**LLM が文書を生成**したり<sup>[\[3\]](#fn-6179-3)</sup>，**アプリケーションから大量の文書を自動生成**したりする機会は格段に増加しています（図 2）．

![情報伝達を支える文書，その作られ方は変わりつつある．レポート，論文，申請書，請求書，マニュアル……．手動での文書作成：人が文章を書き，Word や InDesign で見た目を整える．AI エージェントの活用：LLM（ChatGPT 等）が執筆したレポートを PDF 文書として出力．アプリケーションへの組込：UGC（ブログ記事等）やデータベースから文書を自動生成．](/zenn-images/0bf068d72292-20260830.png)  
_図 2：文書生成の広がり．_

しかしながら，ChatGPT 等の生成 AI を用いて文書を生成すると，見た目が単調になったり，画像生成を介した場合には文字の細部が潰れたりすることがあります（図 3 左）．また，[LaTeX](https://www.latex-project.org/) や [Typst](https://typst.app/) 等の既存の組版システムは，**専用の組版言語を中心に，モノリシックなソフトウェア**として設計されているため，通常のプログラムの一部として組版処理を実行することには主眼を置いていません．そのため，LLM や外部アプリケーションから組版処理を実行しようとすると，TeX/Typst 言語によるソースコードの生成や，外部プロセスの呼び出しを介する必要があります（図 3 右）．

こうした背景を踏まえて，**LLM や外部アプリケーションとの連携を前提**としつつも，高品質な組版処理を柔軟に実行できる仕組みが求められています．

![LLM による文書生成：簡素なデザインになってしまったり，画像生成において文字が潰れてしまったりする．従来の組版システムを活用しようにも……（例：LaTeX，Typst，InDesign）LLM や外部アプリケーションとの連携が難しい．ゆえに，専用の組版言語の習得が必要．](/zenn-images/c6c9592f63b5-20260830.png)  
_図 3：文書生成における課題．LLM による文書も改善傾向にあるものの，依然として「AI っぽさ」を感じることは多いように思います．_

### 日本語組版の特異性

さらに，我々が普段から扱う日本語には，縦組，禁則処理，ルビ，異体字<sup>[\[4\]](#fn-6179-4)</sup>といった，**言語に固有かつ複雑な組版要件**<sup>[\[5\]](#fn-6179-5)</sup>が数多く存在しています（図 4）．こうした処理は海外由来のソフトウェアでは十分に対応されないことも多く，ゆえに日本語による文書生成を支える組版エンジンを，国内で開発することが重要であると考えています<sup>[\[6\]](#fn-6179-6)</sup>．

![日本語組版の複雑さを示す図．縦組，縦中横，約物のアキ調整，混植（明朝 + ゴシック），文字アキ量設定，人名字取り，異体字，モノルビ + 割注の例が並ぶ．ゆえに，日本語組版技術を国内で開発・維持することが重要．](/zenn-images/c4a0a61a6b9b-20260830.png)  
_図 4：日本語組版要件を紹介する際に度々使用しているスライド．_

そこで，LaTeX や Typst 等で実現されている本格的な日本語組版処理や文書作成機能を備えながらも，ライブラリという形で新たな組版エンジンを提供すれば，人手による文書作成に限らず，LLM やアプリケーションを介した新たな文書生成にも高品質な組版処理を組込むことが可能だと考えるに至りました．minitype は，特定のアプリケーションや組版言語に閉じることなく，**様々な文書生成ワークフローから利用できる基盤の組版エンジン**になることを目指しています．

## minitype による文書作成

次に，minitype による文書作成の方法を見ていきます．minitype を実行する最小限のソースコードを以下に示します．[@minitype/minitype](https://www.npmjs.com/package/@minitype/minitype) をインストールしたうえで，以下のプログラムを `tsx index.ts` で実行すると，`hello.pdf` が生成されます．

```typescript
// index.ts
import { h1, minitype, p } from "@minitype/minitype";
await minitype([{
  body: [
    h1("Hello World!"),
    p("minitype のテストです"),
  ],
}]).save("hello.pdf");

```

minitype では，文書の内容やレイアウトを，TypeScript のオブジェクトや関数を組み合わせて宣言的に記述します．例えば，上述のソースコードでは，`h1` 関数で見出しを，`p` 関数で段落を表現した上で，これらの**ブロック要素**を配列として組み合わせることによって文書構造を記述します．作成した配列を `minitype` 関数に渡すと組版処理が実行されます．

見出しや段落に限らず，minitype はリスト，ソースコード，画像，表，数式<sup>[\[7\]](#fn-6179-7)</sup>，脚注，相互参照等，**文書作成に必要となる様々な要素**を標準で用意しています．また，図表や見出しの自動採番，目次，参考文献，Markdown からの変換等は**プラグイン**として実現されています．プラグインは頻繁な利用が見込まれるものを標準提供するほか，ユーザ自身が独自に作成することもできます．

#### レイアウト，スタイル

レイアウトについては，上から下へ要素を並べることに加えて，左右に分けて列を配置する**段組**，ブロックに対して装飾を加える**ボックス**，複数のブロックを横に並べる**フレックスボックス**等を実装しています．例えば，要素を左右に配置する場合，以下のように記述します．これらを組み合わせることにより，レポートのような一般的な文書だけでなく，後ほど紹介するスライドやビジネスレポートのように，複数の要素を自由に配置した文書も作成することができます．

```
flexbox([
  box([p("左カラム")], { inlineSize: ratio(0.3) }),
  box([p("右カラム")]),
]);

```

スタイルに関しては，文書レベルでスタイルを一括指定できるほか，ページレベルでの処理（[group](https://typeset.jp/references/#%E3%82%B0%E3%83%AB%E3%83%BC%E3%83%97group)），複数のブロックに対する一括指定（[section](https://typeset.jp/references/blocks/#%E3%82%BB%E3%82%AF%E3%82%B7%E3%83%A7%E3%83%B3section)），個別のブロックに対する指定が可能です．その他，ページレベルおよび行・文字レベルでの処理として，以下に対応しています．

-   **ページレベルでの処理**  
    ブロック間のスペースの調整（[gap](https://typeset.jp/references/style/#%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E9%96%93%E3%81%AE%E3%82%A2%E3%82%AD)），文書への共通要素の指定（[flow](https://typeset.jp/references/#%E3%83%95%E3%83%AD%E3%83%BCflow)），図版のフロート，垂直スペース，ページの背景画像，図形（矩形／円）描画，改ページ／改段，PDF しおり
-   **行レベルでの処理**  
    書字方向の制御（横組／縦組），禁則処理（追出し，追込み，ぶらさがり処理），分離・分割禁止処理，行取り，欧文組版，ドロップキャップ
-   **文字レベルでの処理**  
    文字色／フォント／文字サイズ／文字揃えの指定，カーニングの調整，合成フォント<sup>[\[8\]](#fn-6179-8)</sup>，禁則処理，文字組アキ量設定<sup>[\[9\]](#fn-6179-9)</sup>，タブ処理，均等割付，インライングラフィック（行中への画像挿入），文中への数式挿入，縦中横，異体字セレクタ・CID・絵文字の挿入，下線，上線，打ち消し線，文字背景，PDF のハイパーリンク

### 他の処理と組み合わせて使用する

minitype は TypeScript ライブラリであるため，通常の Web 開発と同様に，**JavaScript の構文（関数，変数，制御構造等）や API を利用して文書を構成**できます．例えば，配列から文書要素を生成する場合，`map` 関数を使用して以下のように記述できます．

```
const members = ["Alice", "Bob", "Carol"];
const document = [
  h1("Members"),
  ...members.map((name) => p(name)),
];

```

繰り返し使用するレイアウトは React におけるコンポーネントのように，**ヘルパ関数**として切り出すことにより，記述を簡略化することができます．

```
const card = (title: string, description: string) =>
  box([h2(title), p(description)]);
const document = [
  card("Tokyo", "3 nights"),
  card("Kyoto", "2 nights"),
];

```

さらに，[Fetch API](https://developer.mozilla.org/ja/docs/Web/API/Fetch_API) や既存の npm ライブラリ等と組み合わせて，取得・加工したデータをそのまま文書へ流し込むことも可能です．このように，**データの取得・処理・組版を一つの TypeScript プログラムの中で完結**させられる点が，ライブラリとして提供される minitype の大きな特徴になっています．

```
const response = await fetch("https://example.com/api/users");
const users = await response.json();
const document = [
  h1("ユーザー一覧"),
  easytable([
    ["名前", "所属"],
    ...users.map((u) => [u.name, u.organization]),
  ]),
];

```

スペースの都合ですべての仕様を紹介することはできませんが，minitype には他にも様々な機能があります．詳細な使用方法や仕様に関しては，[クイックスタート](https://typeset.jp/quick-start/) や [リファレンス](https://typeset.jp/references/) を参照していただければと思います．

## minitype を使ってみる

ここからは，minitype の具体的な使用方法を示すとともに，minitype が従来の組版システムの域を超えて，様々な場面で活用可能であるというユースケースを紹介していきます．

### 手動での文書作成

まず，手動での文書作成を行う例をご紹介します．minitype 本体は TypeScript ライブラリとして提供されていますが，プロジェクトのセットアップを支援する create-minitype を使用することで，**文書生成を手軽に始められる**ようになっています．Node.js がインストールされた環境で以下のコマンドを実行すると，使用可能な文書のテンプレートが表示されます（図 5）．

```
npm create minitype    # npm
yarn create minitype   # Yarn

```

![ターミナルの画面．ユーザの yarn create minitype という入力に対して，「info Using linked package for "create-minitype". Project name: my-document. Template. Specify a built-in template name, a git URL or a local path.」と表示されている．テンプレートの選択肢には report，technical-book，conference-paper，thesis，invoice，cv，slide，novel，business-report，visual-book が存在する．](/zenn-images/b07199931a19-20260830.png)  
_図 5：create-minitype の実行画面．_

ここでは，学会投稿を想定したテンプレートである `conference-paper` を選択してみます．これにより，文書のビルドに必要なソースコード一式と，@minitype/minitype を含む依存パッケージがセットアップされます．あとは，作成されたディレクトリ配下で `npm run build` を実行することにより TypeScript プログラムが実行され，PDF 文書を生成することができます．

プロジェクトには Vite プラグイン（@minitype/vite-plugin）も併せてインストールされるため，`npm run dev` を実行することにより，リアルタイムプレビュー機能を提供するローカル Web サーバが起動します．プレビュー画面をエディタ内のブラウザに表示することにより，TypeScript のソースコードを編集する度に変更内容が反映され，**仕上がりを確認しながら文書を編集**することができます（図 6）．

![エディタの画面．左側には minitype による文書記述のソースコードが表示されている．右側ではブラウザが起動しており，http://localhost:5174 にて文書のプレビューが表示されている．](/zenn-images/ecc3cefd4896-20260830.png)  
_図 6：vite-plugin の起動画面．左側にソースコードが，右側にローカルサーバ上に起動したリアルタイムプレビュー画面が表示される．_

create-minitype には，この他にもレポート，学位論文，ビジネスレポート，履歴書をはじめとする 10 種類のテンプレートを用意しています．もちろん，ユーザが 1 から TypeScript ソースコードを記述したり，テンプレートを修正してレイアウトやデザインを変更したりすることも可能です．

### Claude Code から使用する

Claude Code 等のコーディングエージェントから minitype を使用することもできます．現在の LLM は TypeScript のコード生成能力も高く，minitype も型定義ファイルやドキュメントを提供しているため，minitype を扱うソースコードをコーディングエージェントが生成・編集することも可能であると感じています．

ここでは，minitype とコーディングエージェントを組み合わせた活用例として，**アプリケーションのセキュリティに関するレポートを自動作成**する例をご紹介します．あえて脆弱性を残したモックアプリに関して，以下のプロンプトを Claude Code に与えると，Claude はソースコードを検査した後，脆弱性を発見して，minitype のソースコードを編集してくれました（図 7）．

```
`./app/src/` 以下のコードをセキュリティレビューして，
```

### 多彩な媒体の組版

先日，未踏アドバンスト事業の成果報告会<sup>[\[10\]](#fn-6179-10)</sup>があり，組版系のプロジェクトのお約束として，発表スライドも当然 minitype を用いて作成しました（図 9）．

![エディタの画面．左側には minitype によるソースコードが表示されている．右側ではブラウザが起動しており，http://localhost:5174 にてスライドのプレビューが表示されている．](/zenn-images/a01219a97d6c-20260830.png)  
_図 9：成果報告会の発表スライドの作成画面．_

見出しの下のプログレスバー（スライドの進行状況を示す）は自動で挿入されるようになっているほか，スライド中に何度か出現するチェックボックス付きリストは，ヘルパ関数を定義することにより，簡潔に記述できるように工夫しています（図 10）．`checkItems` は別ファイルに定義されていますが，こうした定型的なヘルパ関数はもはや LLM に書いてもらえば良いものです．

```
checkItems([
  [
    "専用言語を使用せずに記述",
    [p`特定の組版言語（DSL）に依拠せず\nTypeScript のオブジェクトとして\n宣言的にレイアウトを表現`],
  ],
  [
    "ライブラリとして組版機能を提供",
    [
      p`データ取得・処理・組版までを\n同一のコードベース上で実現`,
      p`➡ アプリケーションと\n　 文書生成処理を統合`,
    ],
  ],
]),

```

### アプリケーションへの組込み

ここからは，アプリケーションへの minitype の組込みを想定したユースケースを 3 つご紹介します．

#### 旅程表生成アプリケーション

海外渡航時などには旅程表などを印刷して携帯することが多いと思いますが，旅程表の出力時に minitype による文書生成機能が組込まれていれば，印刷用にリッチにレイアウトされた文書が生成できるようになります（図 13）．従来，PDF 文書の生成は結構手間の掛かる工程でしたが，minitype を組込むことで，**旅行情報の取得・加工から文書レイアウトまでを同じ TypeScript のコードベース上で扱える**ため，文書生成機能をシームレスに開発することができます．

![旅程表の PDF 文書が表示されている．「東京 → ニューヨーク．山田 太郎 / YAMADA TARO」と上部に表示され，画面中央には搭乗する飛行機の便名，時刻，空港等がボックス形式にて示されている．](/zenn-images/25a06e37fd87-20260830.png)  
_図 13：旅程表の生成例．_

#### Web／印刷用ドキュメントの生成

minitype はサーバサイドでの環境に加えて，ブラウザ上でも動作します．この特徴を活かした例として，[minitype の公式ドキュメントのページ](https://typeset.jp/quick-start/)では，Web ドキュメントに加えて，PDF 文書を出力できるようになっています．ドキュメント自体は Markdown で管理されており，**単一のソースから閲覧用の Web ドキュメントと，印刷・保存・配布用の PDF 文書<sup>[\[11\]](#fn-6179-11)</sup>の両方を生成**（図 14，15）することにより，両者を別々に管理する手間を省くことができます．

![minitype のクイックスタートが表示された Web ブラウザ．「本ドキュメントを PDF で表示」と書かれたピンクのボタンが存在する．](/zenn-images/5c06ec6d4981-20260830.png)  
_図 14：閲覧用の Web ドキュメント．_

![minitype のクイックスタートの PDF 文書が表示された Web ブラウザ．ヘッダには桜の背景画像が表示され，本文は 2 段組で，ソースコードはピンク色の背景のボックスとともに組まれている．](/zenn-images/2f2d52e9afee-20260830.png)  
_図 15：印刷・配布・保存用の PDF 文書．_

#### ブラウザ拡張機能への組込み

さらなる応用として，minitype を埋め込んだブラウザ拡張機能を開発することもできます．この例として，Wikipedia の記事を綺麗に出力・印刷するための拡張機能を考えます．

図 16 に，未踏事業の実施機関でもある[情報処理推進機構（IPA）に関する Wikipedia 記事](https://ja.wikipedia.org/wiki/%E6%83%85%E5%A0%B1%E5%87%A6%E7%90%86%E6%8E%A8%E9%80%B2%E6%A9%9F%E6%A7%8B)の印刷プレビューを示します．ブラウザの標準機能を用いて印刷すると，余白や段組が印刷向けに最適化されておらず，やや読みにくいレイアウトに仕上がってしまうことが分かります．

![情報処理推進機構に関する Wikipedia 記事を Chrome の標準機能で印刷する際のプレビュー画面．1 段組で余白が狭いほか，表が配置されるために本文領域が細くなっている．出典："情報処理推進機構", Wikipedia．Licensed under CC BY-SA 4.0．https://ja.wikipedia.org/wiki/情報処理推進機構](/zenn-images/34610a97a8ad-20260830.png)  
_図 16：Chrome 標準の印刷プレビュー．_

そこで，minitype を組込んだ Google Chrome 拡張機能を使用すると，**印刷しても見やすい二段組の体裁に変換された PDF 文書を出力**することができます（図 17）．この拡張機能では，Document Object Model（DOM）を解析して，HTML 要素を対応する minitype のブロック構造へと変換しています．

![情報処理推進機構に関する Wikipedia 記事の PDF 文書を表示した画面．タイトルと概要を 1 段組で配置した後，本文は 2 段組となっている．ページ上部の柱には「情報処理推進機構 – Wikipedia」と表示されている．出典："情報処理推進機構", Wikipedia．Licensed under CC BY-SA 4.0．https://ja.wikipedia.org/wiki/情報処理推進機構](/zenn-images/b4e7cc2890fe-20260830.png)  
_図 17：minitype を組込んだ Chrome 拡張機能による生成例．_

ここまで見てきたように，minitype を用いることで，人手での文書作成，LLM を介した文書生成，アプリケーションへの組込みという複数のワークフローにて，様々な種類の文書を同一の組版エンジンから生成することができます．
